# Data-Track Prototype (AEMZ)

Прототип модуля визуализации для системы сквозного контроля производственных данных «Дата-Трек». Реализован с акцентом на высокую производительность и точность отображения технологических процессов.

### Технические особенности:
* **Стек:** HTML5 Canvas, JavaScript.
* **Производительность:** Стабильные 60 FPS через `requestAnimationFrame`.
* **Функционал:** 
  * Математическая модель движения заготовки.
  * Отрисовка графика температуры в реальном времени.
  * Динамическое изменение цвета металла в зависимости от нагрева.
